# CODIQ — Product Vision

## What CODIQ is

CODIQ is **not a documentation website**. It is an interactive **Full Stack Developer Laboratory** where learners progress by reading, understanding, experimenting, practicing, solving labs, and becoming independent developers.

The core learning loop:

```
Read → Understand → See Example → Experiment → Solve Challenge → Pass Validation → Complete Module → Move Forward
```

**The goal:** after completing a technology inside CODIQ, the learner should be able to read the official documentation independently — without relying on tutorials.

## Design target

The product should feel like a premium developer tool — in the same class as Vercel, Linear, Raycast, and Stripe Documentation: fast, beautiful, and focused.

## Core principles

1. **No authentication** — nobody should have to create an account to learn.
2. **No backend database** — everything runs in the browser.
3. **Everything in the browser** — lessons, playgrounds, validation, and progress.
4. **User progress is stored locally** — IndexedDB with localStorage fallback.
5. **Extremely fast** — static-first, code-split, lazy-loaded heavy tools.
6. **Beautiful** — dark-first, minimal, premium.
7. **Modular** — every system is separable and reusable.
8. **Content driven** — adding a lesson never requires editing UI code.
9. **Easily expandable** — unlimited future technologies via a registry.
10. **Production ready** — strict typing, tested, documented, accessible.

## Product principles in practice

- **Independence over hand-holding:** lessons teach _why_, then give the learner tools to explore.
- **Validation over opinion:** challenges are graded by a real validation engine, not by comparing strings.
- **Privacy by design:** no accounts, no tracking, no cloud. Progress belongs to the learner.
- **Content is king:** the content pipeline is the most important system in the product.
