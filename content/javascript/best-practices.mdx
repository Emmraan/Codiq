- **Let and const** — avoid `var` in new code
- **Arrow functions** for callbacks and short logic
- **Default parameters** instead of manual fallbacks
- **Strict equality (`===`)** — let coercion surprises stay in legacy code

<CommonMistakes>

- Assuming `==` compares values when it also coerces types
- Mutating state that other functions rely on, invisibly
- Blocking the main thread with heavy synchronous loops

</CommonMistakes>
