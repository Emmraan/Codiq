There is nothing to install for CSS itself — it ships with every browser.

## Write styles three ways

| Approach             | When to use                          |
| -------------------- | ------------------------------------ |
| External stylesheet  | Real projects: `link` a `.css` file  |
| `<style>` block      | Single-page demos                    |
| Inline `style`       | One-off overrides only               |

```html
<link rel="stylesheet" href="/styles.css" />
```
