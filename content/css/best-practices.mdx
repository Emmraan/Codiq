- **Think in classes, not element names** — styles survive markup changes
- **Keep specificity low** — flat, predictable selectors are easier to override
- **Use CSS variables for design tokens** — one change updates the whole theme
- **Prefer logical properties** — `margin-block-start` instead of `margin-top` for international layouts

<CommonMistakes>

- Over-nesting selectors until specificity fights back
- Repeating the same color value instead of defining a token
- Applying layout styles to the same element that handles typography

</CommonMistakes>
