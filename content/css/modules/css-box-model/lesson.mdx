Every element is a box. Know its anatomy and spacing stops being guesswork.

## The four rings

| Layer    | What it does                        |
| -------- | ----------------------------------- |
| content  | The actual text or media            |
| padding  | Space between content and border    |
| border   | The visible edge                    |
| margin   | Space outside the border            |

<Diagram title="Box anatomy">
content → padding → border → margin, outward from the element
</Diagram>

## Shorthand ordering

```css
.box {
  padding: 8px 12px 8px 12px; /* top right bottom left */
}
```

Use two values for vertical/horizontal: `padding: 8px 12px;`.

<Note variant="info" title="Margin collapses">
Adjacent vertical margins combine into one. Use padding inside a container when you need guaranteed space.
</Note>

## `box-sizing`

By default `width` excludes padding and border. Switch to the saner model globally:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```
