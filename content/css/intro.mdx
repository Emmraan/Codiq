CSS turns a boring HTML document into a designed product. It controls colors, spacing, layout and motion — everything that makes a page feel intentional.

## What you will learn

- How the cascade and specificity decide which rule wins
- The box model that every element is built from
- Modern layout with Flexbox and Grid
- Responsive design that works on every screen size

<Note title="No special tools needed">
CSS runs natively in every browser. You can start writing styles with nothing more than a text editor and an HTML file.
</Note>
